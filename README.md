# pairwise-ability-queue

按住技能键不放，角色在前摇结束瞬间又自动接了一段，松手后技能还在飞：输入缓冲只记按下帧，长按和重复触发没区分；施法状态机把前摇、判定期、后摇共用同一个计时器，阶段切换丢事件；取消窗口按固定帧数，网络延迟下客户端能取消、服务器已经结算；动画事件和逻辑状态各自推进，命中帧对不上；冷却在客户端先扣，服务器拒绝后不回滚；资源不足时队列仍保留技能，蓝量恢复后自动放出；打断优先级只比技能 ID，控制效果和沉默分不清；队列深度没有上限，连点把整条队列塞满；手柄和键鼠的重复触发阈值不同，手感不一致；服务器校正只发最终状态，中间施法阶段被跳过；技能释放事件没有幂等键，重试导致双发；切场景时施法队列没清，进新图自动放旧技能；时间缩放时前摇计时按真实时间走，慢动作下技能加速。gameplay/ability_queue.py 是核心，tests/test_ability_queue.py 15个红。要修的是：长按去重；阶段计时；延迟取消；动画事件；冷却回滚；资源校验；打断优先级；队列上限；设备阈值；阶段同步；事件幂等；场景清理；时间缩放。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
